模块化架构

一套接口，无限拼装

即插即用模块

底盘、视觉、机械臂、传感器均以标准接口发布，十分钟完成功能扩展。

统一控制总线

全模块共享 CAN/USB 控制总线，一套 SDK 调度整台机器人，降低集成成本。

开源 SDK 与实训云

提供 Python / C++ SDK 与云端实训环境，课堂教学与课后练习无缝衔接。

云端远程调试

支持远程固件升级与日志回传，教师可在实训云上统一查看班级设备状态。

培训体系

三步进阶的工程能力养成

阶段一

基础认知

ROS 与机器人导论。理解坐标变换、运动学与传感原理，建立系统认知。

阶段二

编程实践

Python 与机器视觉。在实训云上完成目标识别、路径规划与抓取控制项目。

阶段三

工程认证

模块化装配与调试认证。通过整机组装、总线调试与现场排故考核，获得工程能力证书。
